# Документация протокола камеры A9 / PPFT (PPRPC / XCIOT)

## 1. Сетевые параметры и транспорт
- **IP-адрес камеры в LAN:** `192.168.0.101` (локальный TCP-порт управления и медиапотока: `20190`, облачный API: `130.94.89.136:443`).
- **Протокол:** Бинарный фрейминг `PPRPC` поверх TCP с полезной нагрузкой в формате **Google Protobuf (proto3)**.
- **Типы сообщений (`msg_type`):**
  - `mt = 1 / 2`: Рукопожатие и служебные кадры сессии.
  - `mt = 3`: Медиапоток (видео H.264 / MJPEG и аудио G.711 / PCM `subtype=121`, `len=960`).
  - `mt = 4`: Управляющие RPC-команды (`cmd`, `seq`, `rpc_type`, `ciphertext`).

## 2. Аутентификация и шифрование (`a9_proto.py`)
- **Локальная авторизация (`LanAuth`, `cmd = 2650`):**
  - Камера возвращает случайный 32-байтовый hex-токен в поле `1`.
  - На основе `DID`, `SECRET` (из файла `.env`) и сессионного токена вычисляются ключи шифрования управляющего канала (`ctrl_encrypt` / `ctrl_decrypt`).
- **Keepalive / Heartbeat:** `cmd = 106 / 107`, `2780`.
- **Запуск медиапотоков:** Видеопоток (`VideoPlay`) = `cmd = 2610`, Аудиопоток (`AudioPlay`) = `cmd = 2614`.

## 3. Таблица проверенных управляющих команд (Protobuf `proto3`)

| Функция | Команда (`cmd`) | Формат Protobuf (`payload`) | Значения параметров | Статус |
| :--- | :--- | :--- | :--- | :--- |
| **Переключение качества** | `2612` (`VideoQosSet`) | `field 2 (varint)` | `0` = SD, `1` = HD (`1000`, `1001`) | Работает |
| **ИК-подсветка (ночной режим)** | `2635` (`IRCutSet`) | `field 2 (varint)` | `0` = Авто, `1` = Выкл, `2` = Вкл (`1000`, `1001`, `1002`) | Работает |
| **Датчик движения** | `2637` (`AlarmSet`) | `field 1 = channel (0)`, `field 2 = motion` | `0` = Выкл, `1` = Низк, `2` = Сред, `3` = Высок (`08001000`..`08001003`) | Работает |
| **Переворот изображения** | `2646` / `2656` + CSS | `field 1 = channel (0)`, `field 2 = flip` | `1` = Норма, `2` = Горизонт, `3` = Вертикаль, `4` = 180° | Работает |
| **Поворот камеры (PTZ)** | `2664` (`PtzCtrl`) | `field 2 (varint)` | `10` = Стоп, `11` = Вверх, `12` = Вниз, `13` = Влево, `14` = Вправо | Работает |
| **SD-карта: Информация** | `2669..2672`, `2616`, `2621`, `2625` | `field 1 = channel (0)` (`0800`) | Ответ: `field 1 = status`, `field 2 = total_mb`, `field 3 = use_size` | Подключено |
| **SD-карта: Запись по событию** | `2684..2687`, `2628` | `field 1 = channel (0)`, `field 2 = duration` | `0` = Выкл, `30` = Запись 30 сек. | Подключено |
| **SD-карта: Архив (дни)** | `2617..2620`, `2679`, `2681` | `field 1 = 0`, `field 2 = year`, `field 3 = month` | Возвращает дни месяца с записями | Подключено |
| **SD-карта: Форматирование** | `2673..2677`, `2622`, `2626` | `field 1 = channel (0)` (`0800`) | Полная очистка карты памяти | Подключено |

## 4. Технические особенности прошивки
- **Белый прожектор (`ExecIOTCMD`, `cid = 201` / `100`):** Маршрутизируется в нативной библиотеке `libgojni.so` исключительно через облачный HTTPS-шлюз (`130.94.89.136:443`) и не обрабатывается локально на порту `20190`.
- **Запрещённый код `cmd = 2647`:** Вызывает программную перезагрузку камеры и разрыв TCP-сессии (`Connection reset by peer`).
- **Конфликт сокетов:** Перед запуском сервера официальное приложение **FtyCam** должно быть выгружено из памяти телефона.
