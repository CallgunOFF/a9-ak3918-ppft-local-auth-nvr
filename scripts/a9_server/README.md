# Автономный сервер и NVR для IP-камер A9 / PPFT (FtyCam / XCIOT)

Готовое автономное решение на Python для просмотра видео со звуком, записи архива по расписанию или датчику движения (NVR) и полного управления поворотными IP-камерами (префикс `PPFT`) по домашнему Wi-Fi и из интернета через автоперезапускаемый SSH-туннель (`localhost.run`) с мгновенными Push-уведомлениями о смене ссылки через **ntfy.sh**.

---

## Основные возможности
- **Видео и звук в реальном времени:** Просмотр в браузере с адаптацией под мобильный экран и прямые потоки `/live.ts` (MPEG-TS), `/stream.mjpg` (MJPEG), `/snapshot.jpg` (JPEG).
- **Умный видеорегистратор (NVR, модуль `nvr.py`):**
  - Запись видеоархива со звуком в выбранную папку (по кнопке **REC** или автоматически при срабатывании кнопки **🏃 Движение**).
  - Настройка папки хранения (`NVR_DIR`), длительности роликов (`NVR_SEG_MIN`), лимита места (`NVR_MAX_MB`) и скачивание записей прямо в браузере (**кнопка 🎞 NVR**) с сохранением в `.env`.
  - Автоматическая кольцевая очистка старых файлов при заполнении лимита.
- **Управление камерой и телеметрия:**
  - Джойстик поворота (`PTZ`) в правом нижнем углу и 4 независимых режима ориентации изображения (**Нормальный**, **Перевернуть (180°)**, **Отразить горизонт.**, **Отразить вертик.**).
  - Переключение качества (`SD` / `HD`), управление ИК-подсветкой (`Авто` / `Выкл` / `Вкл`), сохранение снимка и полноценный переключатель звука (`AudioContext` Вкл/Выкл).
  - Живая строка телеметрии в углу экрана (`FPS`, битрейт `Kbit/s`, задержка `ms` и оценка качества сигнала).
- **Доступ из интернета без регистрации и карт (`SSH + ntfy.sh`):**
  - Встроенный автоперезапускаемый SSH-туннель (`localhost.run`) поднимает защищённый HTTPS-адрес `https://lhr.life` без установки сторонних VPN-клиентов.
  - При каждом старте или смене ссылки `start.sh` автоматически отправляет кликабельное Push-уведомление в бесплатное приложение **ntfy** (или в Telegram) на 3–4 клиентских телефона.
- **Полная автономность и переносимость:** Установщик `install.sh` работает из любой папки, сам ставит зависимости, настраивает автозапуск при включении телефона (`Termux:Boot`) и держит автоповтор поиска камеры каждые 3 секунды.

## Быстрый старт на любом устройстве (Android + Termux)

### 1. Подготовка телефона-сервера и клиентских смартфонов
1. Установите **Termux** и дополнение **Termux:Boot** (из **F-Droid** или GitHub — оба из одного источника). Откройте **Termux:Boot** один раз.
2. В настройках Android на домашнем телефоне отключите оптимизацию батареи (**Батарея → Без ограничений**) для **Termux** и **Termux:Boot**.
3. Выдайте Termux доступ к памяти командой:
   ```bash
   termux-setup-storage
   ```
4. **Настройка Push-оповещений о смене ссылки (бесплатно, без регистрации):**
   - Придумайте сложное уникальное имя канала (например, `cam_a9_demo_0000`) и впишите его в `NTFY_TOPIC` в `.env`.
   - На свой смартфон (и телефоны близких) установите бесплатное приложение **ntfy** (Google Play / F-Droid) и подпишитесь на это же имя канала.

### 2. Распаковка и настройка `.env`
1. Распакуйте архив проекта в любую удобную папку (например, `Download`):
   ```bash
   tar -xzf FtyCam_Project_Clean_*.tar.gz -C /storage/emulated/0/Download/
   ```
2. Проверьте параметры в файле `scripts/a9_server/.env`:
   ```env
   # Ключи и адрес камеры
   A9_PREKEY=0123456789abcdef0123456789abcdef
   CAMERA_IP=192.168.1.100
   DEFAULT_QUALITY=HD

   # Защита веб-доступа (HTTP Basic Auth)
   WEB_USER=admin
   WEB_PASS=cam2026

   # Локальный видеорегистратор (NVR) и датчик движения
   NVR_ENABLED=0
   NVR_MOTION=0
   NVR_DIR=/storage/emulated/0/Download/Cam_Records
   NVR_SEG_MIN=10
   NVR_MAX_MB=5120

   # Push-уведомления о смене ссылки (ntfy.sh и/или Telegram)
   NTFY_TOPIC=cam_a9_demo_0000
   TG_TOKEN=
   TG_CHAT_ID=
   ```

### 3. Установка и запуск одной командой
Выполните в Termux (указав путь к папке распаковки):
```bash
bash /storage/emulated/0/Download/FtyCam_Project/scripts/a9_server/install.sh
```
Скрипт автоматически установит недостающие пакеты (`python`, `openssh`, `python-cryptography`, `ffmpeg`, `av`), настроит автозапуск при включении телефона (`~/.termux/boot/start_cam.sh`), запустит сервер камеры, поднимет SSH-туннель и пришлёт рабочую ссылку в приложение **ntfy**.

*(Примечание: перед запуском сервера официальное приложение **FtyCam** должно быть выгружено из памяти телефона, так как камера принимает только одно локальное TCP-соединение).*

## Состав файлов проекта
- `scripts/a9_server/install.sh` — **универсальный установщик и первый запуск** (ставит пакеты, настраивает автозапуск и стартует систему).
- `scripts/a9_server/start.sh` — основной скрипт запуска (`wake-lock`, автоповтор поиска камеры каждые 3с, сервер, NVR, SSH-туннель и отправка ссылки в `ntfy.sh` / Telegram).
- `scripts/a9_server/a9_mjpeg_server.py` — HTTP-сервер, стриминг видео/аудио, телеметрия и веб-интерфейс.
- `scripts/a9_server/nvr.py` — модуль видеорегистратора, программного детектора движения и кольцевой очистки диска.
- `scripts/a9_server/a9_proto.py` — бинарный протокол `PPRPC`, шифрование и упаковщик Protobuf.
- `scripts/a9_server/.env` — конфигурация камеры, пароли доступа, настройки NVR и канал оповещений.
- `scripts/a9_server/PROTOCOL.md` — спецификация протокола и таблица управляющих команд `cmd`.
- `ARCHITECTURE_AND_SPECS.md` — полная техническая спецификация камеры, чипсета, приложений и архитектуры.
- `requirements.txt` — список зависимостей Python.

## Расширенное управление камерой (кнопка ⚙ Камера)
- **📍 Точки обзора (пресеты 1–4):** Сохранение текущих координат поворота (`Зап.1..4`) и быстрый переход к ним (`Т1..Т4`).
- **🕒 Время на видео (OSD):** Включение и отключение штампа времени и имени камеры поверх видеопотока.
- **📶 Смена Wi-Fi сети:** Дистанционная настройка нового SSID и пароля Wi-Fi для камеры.
- **🔄 Перезагрузка камеры:** Мягкий удалённый рестарт прошивки камеры в один клик.
