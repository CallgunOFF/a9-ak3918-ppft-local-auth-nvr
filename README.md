# 📷 A9 / Anyka AK3918 / PPFT — Local Auth Bridge, PTZ Patrol & NVR

![Python](https://shields.io)
![Platform](https://shields.io)
![Cloud](https://shields.io)

Автономный локальный сервер-мост и видеорегистратор (**NVR**) для Wi-Fi IP-камер формата **A9 / поворотных PTZ-камер** на платформе **Anyka AK3918 / XCIOT / Linklemo / FtyCamPro** (серийный префикс `PPFT`). Работает **полностью локально без облака производителя**.

## ✨ Основные возможности
- **Прямое подключение по протоколу PPRPC (TCP/UDP `20190`):** локальное рукопожатие `LanAuth`, вычисление сессионных ключей и AES-шифрование команд без доступа камеры в интернет.
- **Веб-интерфейс и стриминг:**
  - Живой поток **MJPEG** (`/stream.mjpg`), **MPEG-TS H.264** (`/live.ts` для VLC / MX Player) и мгновенные снимки (`/snapshot.jpg`).
  - Телеметрия в реальном времени: `FPS`, битрейт (`Kbit/s`), задержка (`ms`) и качество сигнала.
- **Расширенное управление камерой (`⚙ Камера`):**
  - Джойстик поворота **PTZ** + **4 программируемые точки обзора (`T1–T4`)** с сохранением координат в `.env`.
  - **🚓 Умное патрулирование:** автоматический круговой обход сохранённых точек с настраиваемой паузой (`10с / 15с / 25с`).
  - **4 режима ориентации кадра** (Нормальный, 180°, зеркало по горизонтали/вертикали), ИК-фильтр ночного видения, частота антимерцания **50 / 60 Гц**, штамп времени **OSD**, смена Wi-Fi и перезагрузка камеры.
- **Локальный NVR и детектор движения (`nvr.py`):**
  - Непрерывная циклическая запись сегментов `.ts` и автозапись по движению в кадре с настраиваемой чувствительностью.
  - Автоматическая кольцевая очистка старых записей при достижении лимита места на диске.
- **Автозапуск и Push-уведомления:**
  - Готовые скрипты для **Android (Termux + Termux:Boot)** и **Linux** с блокировкой сна (`wake-lock`), автоповтором поиска камеры, SSH-туннелем и уведомлениями в **ntfy.sh**.

## 🚀 Быстрый старт (Termux / Linux)

1. Клонируйте репозиторий и перейдите в папку сервера:
   ```bash
   git clone https://github.com
   cd a9-ak3918-ppft-local-auth-nvr/scripts/a9_server
   ```
2. Создайте файл конфигурации `.env` из шаблона и впишите данные вашей камеры (`CAMERA_IP`, `CAMERA_DID`, `A9_PREKEY`):
   ```bash
   cp .env.example .env
   nano .env
   ```
3. Установите зависимости и запустите сервер:
   ```bash
   bash install.sh
   bash start.sh
   ```
4. Откройте в браузере **`http://127.0.0`** (или локальный IP устройства в сети Wi-Fi).

## 📡 Основные HTTP-маршруты сервера

| Маршрут | Описание |
| :--- | :--- |
| `/` | Веб-интерфейс (видео, PTZ, точки обзора, патруль, NVR) |
| `/stream.mjpg` | Поток `multipart/x-mixed-replace` MJPEG |
| `/live.ts` | Прямой поток H.264 MPEG-TS (совместим с VLC / MX Player / FFmpeg) |
| `/snapshot.jpg` | Текущий стоп-кадр JPEG |
| `/status` | JSON-статус подключения и телеметрия |
