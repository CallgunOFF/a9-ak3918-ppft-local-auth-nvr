> **От автора:** Скрипт делался исключительно под меня и под мои задачи — своими руками я реализовал в нём всё, что хотел, и выжал из этой камеры всё, что только можно было сделать по локальному протоколу без облака.

Автономный локальный сервер-мост и видеорегистратор (**NVR**) для Wi-Fi IP-камер формата **A9 / поворотных PTZ-камер** на платформе **Anyka AK3918 / XCIOT / Linklemo / FtyCamPro** (префикс серийного номера `PPFT`). Работает напрямую в локальной сети **без китайского облака и без доступа камеры в интернет**.

---

## ✅ Что работает и ❌ Что не поддерживается

### ✅ Работает стабильно
- **Локальная авторизация (`LanAuth`, `cmd = 2650`) и AES-шифрование:** прямое TCP/UDP подключение к порту `20190` без облачного шлюза.
- **Живое видео и звук в браузере:**
  - Поток `/stream.mjpg` (MJPEG) и прямой поток H.264 `/live.ts` (для VLC, MX Player, FFmpeg).
  - Захват звука с микрофона камеры (`subtype = 121`) с воспроизведением в браузере через Web Audio API.
  - Телеметрия в реальном времени: `FPS`, битрейт (`Kbit/s`), задержка (`ms`) и оценка качества сигнала.
- **Моторизованный поворот (PTZ, `cmd = 2664`):** ручной джойстик (Вверх / Вниз / Влево / Вправо / Стоп).
- **4 точки обзора (`T1–T4`) и умное патрулирование:** программное запоминание позиций моторов в `.env` и круговой обход сохранённых точек с настраиваемой паузой (`10с` / `15с` / `25с`).
- **Ориентация и параметры изображения:**
  - 4 режима поворота/зеркалирования кадра (`cmd = 2646 / 2656`: Нормальный, 180°, горизонтальное и вертикальное зеркало).
  - Переключение качества `SD / HD` (`cmd = 2612`).
  - Частота антимерцания сети **50 Гц / 60 Гц** (`PowerFreqSet`, `cmd = 2639`).
  - Наложение штампа даты и времени (**OSD**).
- **Локальный NVR и детектор движения (`nvr.py`):**
  - Непрерывная запись видеоархива в сегменты `.ts` и автозапись по движению в кадре с 3 уровнями чувствительности.
  - Автоматическая кольцевая очистка старых записей при достижении заданного лимита диска.
- **Сервисные функции и удалённый доступ:** дистанционная смена Wi-Fi (`cmd = 2662`), перезагрузка камеры (`cmd = 2670`), автозапуск при включении Android через `Termux:Boot`, SSH-туннель и Push-уведомления в **ntfy.sh**.

### ❌ Ограничения аппаратной платформы (не работает)
- **Оптический зум:** на объективе камеры отсутствует моторизованный зум (используется стандартное масштабирование страницы в браузере).
- **Управление белым прожектором / LED:** на бюджетных ревизиях плат `PPFT` белые светодиоды либо не распаяны, либо не управляются по локальному протоколу `PPRPC`.
- **Аппаратные пресеты внутри самой камеры (`PspAdd` / `PspCall`):** из-за отсутствия датчиков угла (энкодеров) на шаговых моторах память точек реализована на стороне нашего сервера по времени хода моторов.
- **Одновременное подключение нескольких клиентов к камере:** прошивка камеры разрешает строго **одно** активное TCP-соединение на порт `20190`. Перед запуском сервера закрывайте штатное приложение FtyCamPro и останавливайте сервер на других устройствах.

## 🚀 Установка и первый запуск (Android Termux / Linux)

1. **Скачайте репозиторий и перейдите в папку сервера:**
   ```bash
   git clone https://github.com
   cd a9-ak3918-ppft-local-auth-nvr/scripts/a9_server
   ```
2. **Создайте файл конфигурации `.env` из шаблона и впишите данные вашей камеры:**
   ```bash
   cp .env.example .env
   nano .env
   ```
   Обязательные параметры в `.env`:
   - `CAMERA_IP` — локальный IP-адрес камеры в вашей Wi-Fi сети (например, `192.168.1.100`).
   - `CAMERA_DID` — серийный номер камеры вида `PPFT...` (указан на наклейке корпуса или в приложении).
   - `A9_PREKEY` — общий 32-символьный hex-ключ платформы (`A2r0i1m1a2M0a1x6toriQue` уже заполнен в `.env.example`, менять не требуется).
   - `NTFY_TOPIC` — имя вашего канала на [ntfy.sh](https://ntfy.sh) для получения ссылки удалённого доступа и тревог движения (необязательно).
3. **Запустите установку зависимостей (`ffmpeg`, `python-av`, `numpy`, `cryptography`):**
   ```bash
   bash install.sh
   ```
4. **Запустите сервер:**
   ```bash
   bash start.sh
   ```
5. Откройте в браузере **`http://127.0.0`** (или `http://<IP_устройства>:8080/` с любого телефона/ПК в домашней сети).

## 🎮 Инструкция по управлению в веб-интерфейсе

- **🔊 Звук:** включает/выключает звук с микрофона камеры (браузер требует одного нажатия для активации аудио).
- **📷 Фото:** сохраняет текущий кадр высокого качества на устройство.
- **🔄 Поворот (Ориентация):** циклически переключает 4 режима ориентации изображения, если камера установлена на потолке или стене.
- **🌙 Ночь:** управление ИК-подсветкой ночного видения (`Авто` / `Выкл` / `Вкл`).
- **🎬 HD / SD:** переключение разрешения видеопотока.
- **🏃 Движение:** включает программный детектор движения. При обнаружении движения в кадре сервер автоматически записывает видеоролик `motion_*.ts` на 45 секунд и отправляет Push-уведомление в `ntfy.sh`.
- **🎞 NVR:** открывает панель видеорегистратора — запуск постоянной записи, выбор папки сохранения (`NVR_DIR`), длительности роликов, лимита места на диске и просмотр/скачивание записанных файлов.
- **⚙ Камера (расширенное управление):**
  1. **Точки обзора (`T1–T4` и `Зап. 1–4`):** поверните камеру джойстиком в нужное место → откройте **⚙ Камера** → нажмите **`Зап. 1`**. Повторите для точек `2`, `3`, `4`. Координаты сохраняются в `.env`, и нажатие **`T1`–`T4`** возвращает камеру в выбранный ракурс.
  2. **🚓 Патруль (`Вкл` / `Выкл` / `10с` / `25с`):** запускает автоматический круговой обход записанных точек с паузой на каждой точке.
  3. **⚡ Частота (`50 Гц` / `60 Гц`):** убирает мерцание и полосы на видео при искусственном освещении от ламп.
  4. **🕒 Время OSD (`Вкл` / `Выкл`):** включает или отключает отображение текущей даты и времени поверх видео.
  5. **Смена Wi-Fi и Перезагрузка:** позволяет перевести камеру на другую точку доступа Wi-Fi или дистанционно перезагрузить её.

## 📡 HTTP-маршруты API

| Маршрут | Формат / Назначение |
| :--- | :--- |
| `/` | Основной веб-интерфейс управления |
| `/stream.mjpg` | Видеопоток `multipart/x-mixed-replace` MJPEG |
| `/live.ts` | Прямой поток H.264 MPEG-TS (для VLC, MX Player, Home Assistant, FFmpeg) |
| `/snapshot.jpg` | Текущий снимок JPEG |
| `/status` | JSON-телеметрия состояния камеры и потоков |
